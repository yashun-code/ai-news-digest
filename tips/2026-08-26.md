## レッスン：settings.json で権限を設定しよう

settings.json の permissions セクションを使うと、Claude Code が使用できるツール・ファイル・コマンドを制限できます。ユーザー・プロジェクト・ローカルの3つのレベルで設定を重ねることで、より詳しい制御が可能です。まずプロジェクトのルートに settings.json を作り、permissions ブロックを追加してみてください。

- kind: lesson
- term: permissions = Claude Code が利用可能なツールやファイルの範囲を決める設定
- term: 階層化設定 = ユーザー→プロジェクト→ローカルの順に上書きして、段階的に権限を絞る仕組み
- try: プロジェクトの settings.json に permissions セクションを追加して、特定ファイルへのアクセスのみ許可するよう制限してください
- source: https://docs.claude.com/ja/docs/claude-code

## セキュリティのメリット

ファイルシステムやコマンド実行の権限を事前に限定することで、意図しない操作やセキュリティリスクを防げます。チーム開発では、プロジェクト設定で共通ルールを決め、個人がローカル設定で追加の制限を加えることが推奨されます。

- kind: skill
- term: 最小権限の原則 = 必要最小限の権限だけを与えることでセキュリティを高める考え方
- source: https://docs.claude.com/ja/docs/claude-code

## 実践：段階的な権限設定

まず全体的なプロジェクト設定を作り、次に自分の環境でさらに厳しい制限を加える流れが効果的です。settings.json のドキュメントを確認して、許可するファイルパターンと禁止するコマンドの組み合わせを試してください。

- kind: md
- term: settings.json = プロジェクト全体の設定ファイル。permissions で Claude Code の動作を制御
- source: https://docs.claude.com/ja/docs/claude-code
