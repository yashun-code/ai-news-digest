## エージェントチェーンの基本
エージェントチェーンとは、ある agent の出力を次の agent の入力にして、複数の役割を連鎖させる方法です。例えば「researcher（研究者）が情報を集め→reviewer（査読者）が確認し→writer（執筆者）が文章にする」という流れで、1つの複雑な仕事を段階的に処理します。Claude Codeの Projects 機能を使うと、こうした複数エージェントをクラウド上で一元管理できます。

- kind: lesson
- term: エージェント＝特定の役割を持つAI。researcher なら情報収集、writer なら文章作成に特化
- try: Claude Code で「3つのエージェントで記事を完成させてください。最初は情報を集め、次に内容を確認し、最後に分かりやすく書いてください」と依頼してください
- source: https://docs.claude.com/ja/docs/claude-code

## カスタムエージェントの定義方法
`.claude/agents/*.md` ファイルを作成すれば、独自のエージェントを定義できます。ファイル名がエージェントの名前になり、Markdown 形式で役割や指示を書きます。複数のエージェントを定義しておくと、自動的にそれらが連携して仕事を進めます。

- kind: skill
- term: カスタムエージェント＝あなたが作ったルールに従うAI。プロンプトを `.md` ファイルで定義
- try: Claude Code で「.claude/agents/researcher.md を作成して、ウェブから最新情報を集める役割を持つエージェントを定義してください」と依頼してください
- source: https://docs.claude.com/ja/docs/claude-code

## Projects で複数エージェントを管理する
Claude Code の Projects 機能は、複数エージェントをクラウド上で一元管理し、ノート PC を閉じた後でもセッションを続けられます。チームで作業する場合も、誰もが同じプロジェクト内の全エージェントにアクセスできます。

- kind: md
- term: Projects＝クラウド上で複数エージェントを保存・共有する空間。作業の中断と再開が自由

## 実践：記事作成チェーンを組む
まず researcher が「Claude Code の最新機能」について 3 つのポイントを調べます。次に reviewer がそれを「正確か、役に立つか」確認します。最後に writer が「初心者にも分かる」文章に仕上げます。各ステップで出力を次の input にするだけです。

- kind: skill
- term: チェーン実行＝ agent1 の出力 → agent2 の input → agent3 の input という流れ
- try: Claude Code で「Researcher は『Claude Code の利点』を 5 つ集めて。それを Reviewer に渡して確認させて。最後に Writer が 200 字の記事にしてください」と依頼してください
- source: https://docs.claude.com/ja/docs/claude-code
