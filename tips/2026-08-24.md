## エージェントチェーンとは
複数の AI エージェントを順番に動かし、前の agent の結果を次の agent が受け取る仕組みです。たとえば、まず researcher が情報を集め、reviewer がそれを検証し、writer が最終的な文章にします。この流れで、単独の agent より正確で質の高い成果が生まれます。

- kind: lesson
- term: エージェントチェーン＝複数の agent を結合させ、段階的に処理を進める自動化パターン
- source: https://docs.claude.com/ja/docs/claude-code

## カスタムエージェントの定義方法
Claude Code では `.claude/agents/*.md` ファイルでカスタム agent を定義できます。markdown ファイル内に agent の役割や実行ルールを書くだけで、チェーン構成に組み込めます。

- kind: skill
- term: agent 定義ファイル＝.claude/agents/ フォルダに置く markdown ファイルで、各 agent の動作と役割を記述したもの
- try: Claude Code で `.claude/agents/researcher.md` ファイルを作り、researcher エージェントの役割を日本語で定義してください
- source: https://docs.claude.com/ja/docs/claude-code

## 実践例：researcher → reviewer → writer
このチェーンでは、researcher が調査、reviewer が精度チェック、writer が文章作成を担当します。各段階で前の出力を参照し、自動的に次の処理へ進みます。

- kind: md
- term: チェーン実行＝前の agent 出力を自動的に次の agent に渡す一連の処理
- try: Claude Code に「Researcher、Reviewer、Writer の3つのエージェントを使って、テーマ『AI とセキュリティ』について調査→検証→執筆するチェーンを設計してください」と依頼してください
- source: https://docs.claude.com/ja/docs/claude-code

## エージェントチェーン成功のコツ
各 agent の出力形式を明確に決めることが重要です。reviewer が reviewer が検証結果を構造化したデータで出力すれば、writer がそれを簡単に利用できます。また、各段階の目標を agent 定義に明確に書きましょう。

- kind: new
- term: 出力形式の統一＝各 agent が次の agent が使いやすいように、決まった形式でデータを渡すこと
- source: https://docs.claude.com/ja/docs/claude-code
