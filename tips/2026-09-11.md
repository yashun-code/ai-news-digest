## 権限管理とは何か
Claude Codeが実行できる操作（ファイル編集・コマンド実行・ツール利用など）を制限する仕組みです。settings.json の permissions セクションで、ユーザー・プロジェクト・ローカルの3階層の設定を上書きして、誰がどの範囲まで操作できるかを細かく制御できます。
- kind: lesson
- term: Permissions = Claude Codeが実行できる操作の許可・禁止を設定する機能
- source: https://docs.claude.com/ja/docs/claude-code

## 3つの設定階層を理解する
settings.json では、権限を3段階で管理します。ローカル設定がプロジェクト設定を上書きし、プロジェクト設定がユーザー設定を上書きします。この階層構造で、プロジェクトごと・環境ごとに細かく権限を調整できます。
- kind: skill
- term: ユーザー設定 = 全プロジェクト共通 → プロジェクト設定 = 特定プロジェクト用 → ローカル設定 = その場限りの制限
- source: https://docs.claude.com/ja/docs/claude-code

## 初めての設定：ファイル操作を制限する
プロジェクトの .claude-code/settings.json を開き、permissions に files セクションを追加して、編集禁止フォルダを指定します。例えば system/ フォルダへのアクセスを禁止すれば、Claude Code が重要なシステムファイルを誤って変更するのを防げます。
- kind: new
- term: files権限 = どのファイル・フォルダをClaude Codeが編集できるか制御する設定
- try: Claude Codeに「settings.json の permissions に files セクションを追加して、system/ フォルダへのアクセスを禁止する設定を示してください」と依頼してください
- source: https://docs.claude.com/ja/docs/claude-code

## コマンド実行権限で安全性を上げる
permissions の commands セクションで、実行許可するコマンドをホワイトリスト方式で指定します。npm install や git push など危険な操作を禁止することで、予期しない環境変更を防ぎます。
- kind: md
- term: commands権限 = ターミナル・シェルコマンドの実行を許可・禁止する設定
- source: https://docs.claude.com/ja/docs/claude-code
