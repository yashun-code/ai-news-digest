## 権限管理とは何か
Claude Code では、AIエージェントが実行できる操作（ファイル読み書き、コマンド実行、ツール使用など）を制限する仕組みが **権限管理（Permissions）** です。settings.json ファイルで `permissions` セクションを設定することで、プロジェクト全体やローカル環境ごとに異なる権限ルールを適用できます。これにより、セキュリティと柔軟性のバランスを取ることができます。

- kind: lesson
- term: Permissions = AIエージェントが実行できる操作の範囲を制限する仕組み
- source: https://docs.claude.com/ja/docs/claude-code

## 3階層の権限設定
Claude Code の権限設定は **ユーザーレベル → プロジェクトレベル → ローカルレベル** の3階層で管理されます。上位のレベルで制限が強いほど、下位の設定でも同じ制限が適用されます。例えば、ユーザーレベルで「ファイル削除禁止」と設定すれば、プロジェクトレベルでいくら緩和しても削除は実行されません。

- kind: new
- term: 階層設定 = より厳しい制限が優先される権限の上下関係
- source: https://docs.claude.com/ja/docs/claude-code

## settings.json で権限を設定する
settings.json ファイルの `permissions` セクションに、許可するツール・コマンド・ファイルパターンを記述します。具体例として、読み取り専用にしたいフォルダや、実行禁止にしたいコマンドを JSON 形式で明記します。設定後は Claude Code を再起動して変更を反映させます。

- kind: skill
- term: settings.json = Claude Code の動作設定を記述するテキストファイル
- try: Claude Code の settings.json に `"permissions": { "readOnly": ["node_modules", ".git"] }` の行を追加してファイルを保存してください
- source: https://docs.claude.com/ja/docs/claude-code

## Auto Mode との関係
Claude Code の Auto Mode では、AIが権限確認を自動で代行し、ユーザーの許可なく操作を実行することができます。権限管理は Auto Mode の動作範囲を限定する最後の砦となり、誤った操作やセキュリティリスクを防ぐ重要な役割を果たします。

- kind: md
- term: Auto Mode = AIが自動的に権限確認を行い、許可された操作のみを実行するモード
- source: https://docs.claude.com/ja/docs/claude-code
