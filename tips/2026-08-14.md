## オートモードって何？
Claude Codeでコードを実行するとき、これまでは「本当に実行していいの？」と毎回人間に確認を求めていました。オートモードはこの確認を自動化し、危険でないコマンドなら AIが自動で判定して実行します。ボタンを何度も押す手間がなくなり、作業がスムーズになります。

- term: オートモード＝危険でないコマンド実行を AIが自動判定する機能
- try: Claude Codeでファイル作成やコマンド実行するとき、オートモードがデフォルトで動作するか確認してみてください

## 実装された日時と背景
2026年8月14日からオートモード がデフォルトで有効になります。従来はユーザーがすべてのコマンド実行を承認していたため、開発効率が低下していました。Anthropic は AI が安全性を判定できるようになったため、この機能をデフォルト化することを決定しました。

## Claude Code の安全性判定の仕組み
AIが危険な操作（システム削除、不正アクセス試行など）と安全な操作（ファイル作成、パッケージインストールなど）を自動的に区別します。危険と判定されたコマンドは自動実行されず、人間の承認を求める機能は残ります。

- kind: md
- term: 危険操作自動判定＝AI が悪意のあるコマンドを検出して実行をブロック
- source: https://news.google.com/rss/articles/CBMiU0FVX3lxTE1Gc0hWQnBFNUlVTWs2RnBhRGhlYUNqMW14dEFCdGEyNmxCZjRLTmlBU0hSTUVaQ2NfMGFEcEhIbExpVTJlYzJlNGFMLUFIQzhpZzQ0

## オートモードの設定を確認する方法
Claude Code を開き、設定メニューから「オートモード」の項目を探します。トグルがオンになっていれば、新しい機能が有効です。安全性が心配な場合は、ここからオートモードをオフにして従来の承認方式に戻すこともできます。

- kind: skill
- term: トグル＝オン・オフを切り替えるスイッチ型の設定ボタン
- try: Claude Code の設定画面を開いて、オートモード がデフォルトでどのような状態になっているか確認してみてください
- source: https://docs.claude.com/ja/docs/claude-code
