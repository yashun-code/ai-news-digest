## /code-review で他人のコードをチェック
他人が書いたコードの品質を確認したいときは `/code-review` スキルを使います。セキュリティ問題や可読性の問題を自動で見つけてくれます。試しに、あなたが心配なコードをClaudeに貼り付けて、「このコードを /code-review で確認してください」と言うだけ。改善提案がすぐに返ってきます。

- kind: lesson
- term: /code-review＝コードの問題点（セキュリティ、バグ、読みやすさ）を自動検査するスキル
- try: 以下のコードを確認してください。/code-review を使って問題点を教えてください：def login(user, password): if user == "admin" and password == "1234": return True
- source: https://docs.claude.com/ja/docs/claude-code

## /debug でバグを素早く修正
プログラムが動かない、エラーが出ている……そんなときは `/debug` スキルの出番です。エラーメッセージをコピーしてClaudeに見せれば、原因と直し方を教えてくれます。修正後のコードもそのまま使えます。

- kind: skill
- term: /debug＝エラーメッセージから原因を特定し、修正方法を提案するスキル
- try: TypeError: unsupported operand type(s) for +: 'int' and 'str' というエラーが出ています。/debug で原因を教えてください
- source: https://docs.claude.com/ja/docs/claude-code

## この2つのスキルを組み合わせる
新しいコードを書いたら、まず `/code-review` で品質チェック。それから実行してエラーが出たら `/debug` で修正。この流れを繰り返せば、安全で動くコードができあがります。

- kind: md
- term: バンドルスキル＝複数の専門スキルを組み合わせて、開発作業全体を効率化する方法
- source: https://docs.claude.com/ja/docs/claude-code

## さらに便利な使い方
コードを共有フォルダに置いて、複数のスキルを連続実行させることもできます。`/code-review` → `/debug` → `/run` の順で実行すれば、「チェック → 修正 → 動作確認」が一気にできます。

- kind: new
- term: スキルチェーン＝複数のスキルを自動でつなげて実行する使い方
- source: https://docs.claude.com/ja/docs/claude-code
