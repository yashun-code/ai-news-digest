## エージェントチェーンとは
エージェントチェーンは、複数のAIエージェント（チャットボット）を つなげて、前のエージェントの出力を次のエージェントの入力にする多段構成です。たとえば「調査担当」→「確認担当」→「執筆担当」のように、役割を分けることで、より正確で質の高い結果が得られます。

- kind: lesson
- term: エージェント＝ある目的を持ったAI、チェーン＝それらをつなげる流れ
- source: https://docs.claude.com/ja/docs/claude-code

## 基本パターンを理解する
エージェントチェーンの代表例は researcher（調査役）→ reviewer（レビュー役）→ writer（執筆役）の3段階です。researcher が情報を集め、reviewer がその情報の正確さを確認し、writer が最終的な文章にまとめます。この流れにより、各段階で品質チェックが入るため、ミスが減ります。

- kind: skill
- term: Researcher-Reviewer-Writer パターン＝品質を高める標準的な構成
- source: https://docs.claude.com/ja/docs/claude-code

## Claude Code でカスタムエージェントを作る
Claude Code の `.claude/agents/` フォルダ内に `.md` ファイルを作ると、独自のエージェントを定義できます。各エージェントには名前、役割、出力形式を明記して、次のエージェントに正確に渡せるようにします。

- kind: md
- term: .claude/agents/*.md＝カスタムエージェントの定義ファイル
- try: Claude Codeで「.claude/agents/researcher.md」を作成して、調査用エージェントのプロンプトを書いてください
- source: https://docs.claude.com/ja/docs/claude-code

## 実践：今すぐ試してみる
Claude Code で下記のように依頼して、エージェントチェーンの流れを体験してください。「まず調査して、その結果を確認して、最後にまとめる」という3段階の指示を出すと、段階ごとに異なる質の応答が返ってきます。

- kind: new
- term: パイプライン＝エージェント同士の「情報の流れ」
- try: 「テーマ『AI開発の最新トレンド』について、調査→確認→執筆の3段階で進めてください」とClaude Codeに依頼してください
- source: https://docs.claude.com/ja/docs/claude-code

## 応用：複雑なタスクに対応する
エージェントチェーンは2段階、3段階だけでなく、5段階以上の複雑な流れにも対応できます。例えば企画→調査→執筆→デザイン指示→最終確認のように、大きなプロジェクトを細かく分割すれば、各エージェントの集中度が上がり、成果物の品質が向上します。

- kind: skill
- term: マルチステップパイプライン＝複数の確認ステップを含む長い流れ
- source: https://docs.claude.com/ja/docs/claude-code
