## CLIワンショット実行の基本

Claude Codeをコマンドラインから1回だけ実行するには `claude -p 'メッセージ'` を使います。結果がすぐターミナルに表示されるので、スクリプトやGitHub Actionsの中で自動実行するのに最適です。今日は実際に試してみましょう。

- kind: lesson
- term: ワンショット実行 = Claude に1回だけ指示を出して、すぐ結果をもらう方法。対話を続けず終了する
- try: ターミナルで `claude -p 'こんにちは。今日の日付を教えてください'` を実行してみてください
- source: https://docs.claude.com/ja/docs/claude-code

## GitHub Actionsに組み込む

GitHub Actions のワークフロー内で `claude -p` を使うと、プッシュやスケジュール実行のたびに自動でAIタスクを実行できます。例えばコード生成やテスト結果の要約がCI/CDパイプラインの中で動きます。

- kind: skill
- term: GitHub Actions = リポジトリに特定のイベント（プッシュなど）が起きたときに自動でスクリプトを実行する機能
- try: .github/workflows/claude-task.yml に `run: claude -p 'README.mdを確認してコメントを追加'` というステップを書いて、プッシュ時に自動実行してみてください
- source: https://docs.claude.com/ja/docs/claude-code

## ワンショット実行が活躍する場面

日々の開発ではワンショット実行が大活躍します。テストコードの生成、ドキュメントの校正、ログファイルの分析など、短時間で終わるタスクに向いています。複雑な対話は不要で、「指示を出す → 結果をもらう」がスピーディーです。

- kind: md
- term: CI/CD = コード変更を自動でテスト・ビルド・デプロイするパイプライン
- source: https://docs.claude.com/ja/docs/claude-code

- kind: new
