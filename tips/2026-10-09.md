## CLIワンショットの基本
`claude -p 'メッセージ'` コマンドをターミナルで実行すると、Claude が1回だけ応答して終了します。複雑な操作不要で、シンプルなタスク（ファイルの確認、エラー解析、ドキュメント生成）に最適です。

- kind: lesson
- term: CLIワンショット＝コマンドラインからAIに1回だけ質問して答えをもらう使い方
- try: `claude -p 'このJavaScriptファイルのバグを探してください'` という形で、ファイルの内容を確認させてみてください
- source: https://docs.claude.com/ja/docs/claude-code

## GitHub Actions で自動実行
ワークフローファイル（`.github/workflows/` フォルダ内）の `run:` ステップに `claude -p` コマンドを書くと、プッシュやプルリクエストのたびに Claude が自動で実行されます。

- kind: skill
- term: GitHub Actions＝リポジトリのイベント（プッシュなど）をトリガーに、自動でジョブを実行する機能
- try: `.github/workflows/review.yml` を作成し、`run: claude -p 'コミットメッセージを見直してください'` と書いて保存してください
- source: https://docs.claude.com/ja/docs/claude-code

## 実用例：コードレビュー自動化
プルリクエストが開かれたとき、Claude に差分ファイルを見せて品質チェックさせる設定ができます。結果はコメントとして自動追加されます。

- kind: new
- term: CI/CD パイプライン＝コード変更から本番環境までの自動実行フロー
- source: https://docs.claude.com/ja/docs/claude-code

## セットアップのコツ
API キーを GitHub Secrets に登録し、ワークフローから安全に参照します。機密情報を YAML に直書きしないようにしましょう。

- kind: md
- term: GitHub Secrets＝リポジトリの秘密情報を安全に保管する仕組み
- source: https://docs.claude.com/ja/docs/claude-code
