## Claude Codeとは何か
Claude Codeは、AIがあなたのコード作成をサポートするツールです。プログラムを書いたり、修正したり、説明したりするのを手伝います。あなたは何をしたいか説明するだけで、Claude Codeが実際のコードを書いてくれます。

- kind: lesson
- term: Claude Code＝AIコーディングアシスタント。プログラムを作るときに手伝ってくれるツール
- source: https://docs.claude.com/ja/docs/claude-code

## 初めての依頼を試す
1. Claude Code を開きます
2. 「シンプルな自己紹介を表示するHTML を作って」と依頼します
3. Claude がコードを書いてくれるのを見て、何をしたか読みます
4. 「背景色を青に変えて」と追加の依頼をして、修正を見ます

- kind: skill
- term: プロンプト＝AIへの指示。やりたいことを日本語で書いて送ります
- try: シンプルなカウンターを作れるHTMLとJavaScriptを書いてください
- source: https://docs.claude.com/ja/docs/claude-code

## コードの質問をする
Claude Code に「このコードは何をしていますか？」と聞いて、書かれたプログラムの説明をもらいます。難しい部分があれば「forループの説明を簡単に」と言えば、わかりやすく説明してくれます。

- kind: skill
- term: コードレビュー＝AIにプログラムを読んでもらい、何をしているか説明してもらうこと
- source: https://docs.claude.com/ja/docs/claude-code

## 修正と改善を依頼する
作ったコードに問題があったら「エラーが出ます、直してください」と送ります。改善したいなら「このコードを速くする方法はありますか？」と聞いて、Claude からの提案を見ます。

- kind: skill
- term: デバッグ＝プログラムの間違い（バグ）を見つけて直すこと
- try: このコードのエラーを直してください。エラー内容は～です
- source: https://docs.claude.com/ja/docs/claude-code
