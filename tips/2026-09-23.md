## Claude CLI のワンショット実行

Claude Code は `claude -p 'メッセージ'` でターミナルから 1 回だけ実行できます。ファイルの修正や検証が素早くできるため、開発の効率が大幅に上がります。下記の手順で試してみましょう。

1. ターミナルを開き、`claude -p 'Hello と言ってください'` と入力して実行する
2. Claude が応答を返す
3. 同じコマンドで異なる指示を与えて、何度でも実行できることを確認する

- kind: lesson
- term: ワンショット実行 = 1 つの指示を与えて、即座に結果を受け取る実行方法
- try: Claude CLI を使って「今日の日付を教えてください」とワンショット実行してください
- source: https://docs.claude.com/ja/docs/claude-code

## GitHub Actions で自動実行

ワンショット実行を GitHub Actions のステップとして組み込めば、Push やスケジュール実行時に Claude が自動的に処理を行います。CI パイプラインの一部として活用できます。

- kind: skill
- term: GitHub Actions = GitHub 内で自動実行される CI/CD ワークフロー
- try: リポジトリの `.github/workflows/` に `claude-step.yml` ファイルを作り、`run: claude -p 'コードをチェックしてください'` というステップを追加してください
- source: https://docs.claude.com/ja/docs/claude-code

## CLI から GitHub Actions への流れ

ローカルで動作確認してから、ワークフローに組み込むことで、本番運用がスムーズになります。トークン消費を意識しながら効率的に活用できます。

- kind: md
- term: トークン = Claude が処理する言葉の単位。入出力で消費される
- source: https://docs.claude.com/ja/docs/claude-code
