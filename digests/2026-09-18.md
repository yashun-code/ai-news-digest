## Anthropic、Claude の「チャット」と「Cowork」を統合―ドキュメント作成ツールも追加

Anthropic は **Claude Code Projects** を発表。従来は別々だったチャットとコード開発環境「Cowork」を一つのインターフェースに統合し、長時間にわたる開発作業をメモリに保持しながら自動で段階的に進める「常時稼働型の会話」を実現。さらに **Docs** と **Slides** の生成機能も新たに追加し、資料作成まで一貫してこなせるように。

- term: Claude Code Projects＝長時間実行するコード開発を自動で管理し、やりとりの文脈を保持し続けるAI環境
- relate: 複数言語やマルチファイルプロジェクトを効率的に開発でき、開発生産性が大幅に向上。フリーランスや小規模チーム向けのツール習熟価値が高い。

## Google、「Gemini 3.8 Live」発表――話しながら推論・ツール実行が可能に

Google が新型音声AI「**Gemini 3.8 Live**」と上位版「**Gemini 3.8 Live Extended Thinking**」を正式発表。従来の音声AIは完全に話し終わるまで応答できなかったが、新モデルは会話を止めずに裏側で推論を進めたり、必要に応じてツール実行・情報検索を並行処理。**97言語対応**で、低コストながら高度な推論能力を実現。

- term: Extended Thinking＝AIが複雑な問題を時間をかけて「考える」ステップを内部に持つ機能
- relate: 音声インターフェース経由でのカスタマーサポート・データ分析・意思決定支援など、リアルタイム対話が必須のビジネスアプリに即活用可能。

## xAI、Grok Build に「クロスセッションメモリ」を追加――コーディングエージェント強化

- term: クロスセッションメモリ＝複数回の独立した会話でも、過去の文脈・決定を保持し続けるAI機能
- relate: 複数日にわたるプロジェクト開発やイテレーティブな設計が効率化。小規模チームや個人開発者のコード自動生成活用が加速する。

## NEC、サプライチェーン業務を自動化する「SCM AIエージェント」を9月に発売

NEC が自律型AI「**NEC SCM AIエージェント**」を発表。在庫管理・需要予測・仕入れ最適化などサプライチェーン全般の意思決定を自動で実行。人間の指示を待つのではなく、システムが自ら判断して業務を進める「本当の自律型」エージェント。製造業向けの大型案件獲得へ向けて9月中に販売開始予定。

- term: 自律型AIエージェント＝人間の指示なしに、判断と実行を繰り返すAI（従来の「質問に答えるAI」とは別物）
- relate: 製造・物流業務の効率化が加速。既存のSCMシステム導入企業が競争力を失う可能性もあり、新規事業化や既存ツール刷新のチャンス。

## Meta、パーソナル「Muse」エージェント提供開始――自律的にタスク処理

Meta が個人向けAIエージェント「**Muse**」を提供開始。単なるチャットボットではなく、ユーザーが掲げた目標に対して自律的にタスクを分解・実行・進捗管理。ユーザーは方向性を示すだけで、細かい作業は Muse が判断して進める仕組み。キャリア・プロジェクト管理から日常生活支援まで広く活用可能。

- relate: 個人の生産性向上だけでなく、小規模ビジネスの運営自動化にも応用可能。AIエージェント時代への適応が急務。
